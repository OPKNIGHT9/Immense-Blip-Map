Admin tool

Generates the contents of data/blips.js and data/users.js. Everything runs in this page — nothing is sent anywhere. Run it locally and paste the output into the data files, then commit.

Keep your group keys somewhere safe (a password manager). You need a group's key to encrypt new blips for it or to add another member. If you lose it, you have to generate a new key and re-encrypt that group's blips, which locks out everyone holding the old one.

1. Group key

Each group needs one key. Generate it once, save it, and reuse it whenever you re-encrypt that group's blips or add a member.

2. Encrypt a group's blips

Paste the blips as a JSON array. The output goes into the groups section of data/blips.js.

3. Create a member account

Produces one record for data/users.js. The password is never stored — only a verifier and the group keys wrapped with it.

4. Check an encrypted payload

Paste a group key and its encrypted string to confirm it decrypts to what you expect.
